# Flix Home

Experimental, vibe-coded launcher for the Samsung UE43NU7409 (2018, Tizen 4.0).
**0.6.1**: flat black / ivory themes, minimal glass, one local brand-coloured
focus light and a folding square-pixel clock. Installed on the target TV; its
owner confirmed the light and folding digits work.

**Physical Home replacement and reliable boot/standby autostart remain open.**
